# cliphive

Clip filesystem hive paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/cliphive/

## Install / run

```bash
git clone https://github.com/theworker02/cliphive.git
cd cliphive
node src/cli.js
node --test
```
